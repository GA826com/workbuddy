# 交付武器库 · 接单后的生产流程

> 用途：接到单之后，用这套流程把交付时间压到同行的 1/3。
> 你负责接单和验收，产出环节全部可交给 AI 打底 + 你人工把关。
> **核心原则：AI 出骨架，人出判断和语感。绝不能直接把 AI 原文交给客户。**

---

## 一、去 AI 味改写规则（每一单交付前必做）

客户现在对"AI 味"极其敏感，一旦被识破就是差评。以下 8 条是硬规则：

| 症状 | 改法 |
|---|---|
| 满篇"首先/其次/最后"、"综上所述" | 全部删掉，换成自然过渡或直接分段 |
| 三段式排比堆砌（"不是…而是…"连用） | 拆散，只保留一处最有力的 |
| 书面语过度：赋能、抓手、闭环、生态、维度 | 换成具体动作词：做、改、对接、落地 |
| 句子长度整齐划一 | 长短句交替，关键处用短句砸下去 |
| 空泛形容词：极大地、深刻地、全方位 | 删掉，或用数字替换（"提升 40%"） |
| 每段开头都是主题句 | 允许从细节、场景、对话切入 |
| 结尾必升华、必喊口号 | 改成具体建议或留一个开放问题 |
| 破折号和引号泛滥 | 通读一遍，砍掉一半 |

**最后一道工序：把稿子念出声。** 念着别扭的地方，就是 AI 味所在。这招比任何检测工具都准。

---

## 二、分品类生产提示词

> 用法：复制下方整段，把【】替换后发给任意大模型。
> 拿到初稿后，**必须**按第一节做去 AI 味处理 + 事实核查，再交付。

### 1 · 公众号推文

```
你是资深公众号内容编辑。请为一篇公众号文章生成初稿。

【基础信息】
主题：
账号定位：
目标读者：（年龄、身份、他们关心什么）
字数：1500 字左右
发布目的：（涨粉/转化/品牌/科普）

【写作要求】
1. 标题给 5 个备选，分别对应：数字型、悬念型、利益型、反常识型、场景型
2. 开头 100 字内必须抓住人，禁止"随着…的发展"这类开场
3. 正文分 3–4 个小节，每节有小标题，每节只讲一件事
4. 每个观点后面必须跟一个具体例子、数据或场景，禁止只讲道理
5. 语言口语化，允许短句，允许口语词，像人在说话而不是在写报告
6. 结尾给一个明确行动建议，不要喊口号

【禁止】
- 不要出现"首先/其次/最后""综上所述""值得注意的是"
- 不要用"赋能、抓手、闭环、生态、维度、赛道"这类词
- 不要三段式排比堆砌
- 不要空泛升华结尾

先输出大纲，我确认后再写正文。
```

### 2 · 品牌软文 / 商业稿

```
你是商业内容策划。请写一篇品牌软文初稿。

【产品/服务】
【品牌调性】（高端/亲民/专业/活泼）
【投放渠道】（公众号/小红书/官网/媒体稿）
【核心卖点】（最多 3 个，多了记不住）
【目标读者痛点】
【字数】

【结构要求】
1. 从读者痛点切入，不要从品牌历史切入
2. 痛点 → 原因 → 解决方案 → 自然带出产品（产品出现在全文 1/3 处）
3. 卖点部分必须每个配一个使用场景
4. 结尾引导动作要具体（去哪、做什么），不要"欢迎咨询"

【禁止】
- 不要自夸式形容词堆砌（领先、卓越、极致）
- 不要虚假承诺和绝对化用语（最、第一、100%、根治）——违反广告法
- 不要 AI 腔

先给标题 5 个备选 + 大纲，确认后写正文。
```

### 3 · 演讲稿

```
你是资深撰稿人。请写一篇演讲稿初稿。

【演讲者身份与职务】
【场合】（会议/比赛/颁奖/竞聘/开学典礼）
【听众构成】
【时长】X 分钟（按每分钟 200 字折算字数）
【核心要传达的一句话】

【硬性要求】
1. 这是"说"的稿子不是"看"的稿子：句子要短，多用口语，长难句一律拆开
2. 开头 30 秒内必须有一个钩子（提问/故事/反常识判断），禁止"尊敬的各位领导，大家好"之后直接进正题
3. 全文设置 3 个记忆点：一句金句、一个故事、一个数字
4. 结尾要能引发掌声——落到情感或行动，不要落在"谢谢大家"就完了
5. 标出需要停顿的位置（用「停顿」标注）和需要加重的位置（用「重音」标注）

【禁止】
- 不要书面语长句， speaker 念到会断气
- 不要排比句连用超过 2 组
- 不要空话套话

先给大纲和开头 3 版，我选一个方向再写全文。
```

### 4 · 述职报告 / 工作总结

```
请写一篇【述职报告/工作总结】初稿。

【本人信息】岗位、任职年限、单位性质
【时间范围】
【主要工作内容】（列 3–5 项，每项尽量给具体数据和结果）
【取得的成绩】（能量化的一定量化）
【存在不足】（要真实，要有反思深度，不能全是"学习不够"）
【下阶段计划】
【字数】

【结构】
一、思想政治与履职概况（简短，不空谈）
二、主要工作与成效（重点，占 60%，每项按"做了什么—怎么做的—结果如何"写）
三、存在问题与原因分析（真诚，具体到事）
四、下一步打算（可落地，有时间点）

【文风要求】
- 体制内规范文风：平实、准确、谦逊，不浮夸
- 用数据和事实说话，少用形容词
- "不足"部分要写得像真反思，不要模板化的套话
- 不用 AI 腔调

先列提纲，确认后写正文。
```

### 5 · 教案 / 说课稿

```
你是经验丰富的一线教师。请撰写一篇教学设计。

【课题】【年级】【学科】【课时】
【教材版本】
【教学目标】（知识与能力 / 过程与方法 / 情感态度价值观）
【教学重难点】
【学情分析】

【输出格式】
一、教学目标（分三条，用可观察的行为动词：能说出、能分析、能写出）
二、教学重难点及依据
三、教学方法与依据
四、教学过程（分环节，每个环节标注：教师活动 / 学生活动 / 设计意图 / 时间分配）
   含：导入（要有情境）、整体感知、深入研读、拓展延伸、小结作业
五、板书设计（用文本画出板书结构）
六、教学反思预设（真实可写，不要套话）

【特别要求】
- 提问设计要具体，写出实际问句，不要写"引导学生思考"
- 学生活动要可操作，不要抽象
- 体现新课标理念：学生主体、任务驱动、情境教学
- 语言专业规范，符合教研评审口味

先给教学流程框架，确认后写全文。
```

### 6 · 短视频脚本

```
请写一条短视频脚本。

【平台】（抖音/视频号/小红书）【时长】X 秒
【主题】【目标人群】
【目的】（引流/涨粉/带货/科普）
【人设】（讲述者是什么身份、什么语气）

【脚本格式】
按时间轴分镜，每行格式：
[时间] 画面描述 | 口播文案 | 备注（字幕/音效/镜头）

【硬性要求】
1. 前 3 秒必须有钩子：冲突、悬念、反常识、利益点，四选一
2. 每 5 秒要有一个信息增量或情绪变化，不能平铺直叙
3. 口播文案按口语写，按说话节奏断句，每句不超过 15 字
4. 结尾给明确的互动引导或行动指令

【禁止】
- 不要开场自我介绍
- 不要书面语
- 不要超过【时长】对应的字数（按每秒 4 字估算）

先给 3 个不同的开头钩子，我选一个再写完整脚本。
```

### 7 · PPT 大纲（做课件前先出这个）

```
请为一份 PPT 设计内容大纲。

【主题】【用途】（汇报/培训/路演/赛课/招商）
【受众】【页数】【时长】
【已有素材】（文字稿/数据/产品资料）

【输出要求】
1. 先给出整体叙事线：用一句话概括这份 PPT 要讲清楚什么，再拆成 3–5 个章节
2. 逐页输出，每页包含：
   - 页面标题（要像标题，不要像标签）
   - 核心信息（这一页要让观众记住的一句话）
   - 内容要点（不超过 3 条）
   - 建议呈现形式（文字/图表/图示/图片/对比表）
3. 标注哪些页需要图表，并说明图表类型
4. 标注逻辑转折点（哪里需要过渡页、哪里需要强调页）

【原则】
- 一页只讲一件事
- 标题要能连起来读成一篇完整的话
- 能图示化的不用文字，能对比的不用罗列

先输出叙事线和章节划分，确认后再细化到页。
```

## 三、交付前自检清单（每一单必过）

- [ ] **需求核对**：逐条对照雇主任务描述，确认每一项都有回应，没有遗漏
- [ ] **去 AI 味**：按第一节 8 条规则过一遍，念出声检查
- [ ] **事实核查**：涉及数据、人名、专业术语的，全部核实一遍（AI 会编数据）
- [ ] **合规检查**：无绝对化用语、无医疗功效承诺、无虚假宣传（广告法红线）
- [ ] **格式检查**：字号统一、段落间距统一、无错别字、标点规范
- [ ] **查重**：文案类跑一遍查重，控制在 15% 以内
- [ ] **交付物齐备**：正文 + 源文件 + 说明文档（如有约定，附版权协议）

## 四、时间账：这套流程能省多少

| 品类 | 传统人工 | 本流程 | 你的实际投入 |
|---|---|---|---|
| 公众号推文 1500 字 | 3–4 小时 | 40 分钟 | 提示词 5 分钟 + 改写 30 分钟 + 检查 5 分钟 |
| 述职报告 3000 字 | 6–8 小时 | 1.5 小时 | 素材整理是大头，写作本身 40 分钟 |
| 20 页标准课件 | 8–12 小时 | 3 小时 | 大纲 30 分钟 + 制作 2 小时 + 校对 30 分钟 |
| 短视频脚本 | 1 小时 | 15 分钟 | 选题 10 分钟 + 改写 5 分钟 |

**结论**：按每天晚上 2 小时算，一周能稳定交付 3–5 单。这是你在不影响教学前提下 realistic 的上限——接单别超过这个量，否则必然翻车。
